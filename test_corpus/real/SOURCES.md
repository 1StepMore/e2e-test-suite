## Rejected / Unavailable Sources

The original task list mentioned the following sources; they were either unreachable
from the build environment (network-blocked) or replaced with public-domain equivalents
of the same character:

- **Wikipedia (4 articles)**: `History of the English language`, `Mathematics`,
  `Quantum mechanics`, `Climate change`.
  - Wikipedia's API endpoint (`en.wikipedia.org`) and the Wikimedia Foundation's
    network (208.80.152.200, 2620:0:861:ed1a::1) were unreachable from the WSL build
    environment — `curl` returned `000` / connection timeout over both IPv4 and IPv6.
  - Mirrors tested and also blocked: `wikiless.org`, `wikiwand.com`.
  - Replaced with US-government public-domain sources of equivalent expository character
    (Federal Reserve, NASA).
- **US Census / BLS / Library of Congress**: all returned `403 Forbidden` from the
  WSL build environment. Replaced with Federal Reserve + NASA public-domain sources.
- **USGS / archive.org**: blocked (`000` / `403`). Replaced with Federal Reserve + NASA.
- **Recipe from `The Kentucky Receipt Book` (pg17566)**: not required after Robert May's
  *The Accomplisht Cook* (pg22790, 1665) was selected as a representative public-domain
  cookbook.
- **arXiv, GitHub READMEs, commercial documents**: explicitly excluded per the task
  brief (no full books, no copyrighted, no commercial).

## File Format

Each `.txt` file starts with a 6-line header comment:

```
# <Title>
# Author: <Author>
# Source: <URL>
# License: <License>
# Excerpt: <Chapter / section / range>

<body text>
```

The header is followed by the extracted body text. The body is plain UTF-8 with
newlines normalized to `\n`. Project Gutenberg boilerplate (front-matter license,
transcriber notes, `*** START/END OF THE PROJECT GUTENBERG ***` markers, back-matter)
is removed before saving.

## Curation Notes

- Chapter boundaries were detected by regex over the stripped Project Gutenberg text,
  with explicit table-of-contents / `EXTRACTS` section skipping for books like
  *Moby-Dick* whose front-matter contains `CHAPTER 1. Loomings.` as a TOC entry
  before the actual chapter 1 (`Call me Ishmael...`).
- The `Federal Reserve` and `NASA` files are HTML-to-text extracts; the relevant
  text content div was identified by `class="content-block-text"` (Fed) and
  `<main>` / article-tag fallbacks (NASA).
- Two files are at the 49.9 KB cap (Time Machine ch.1, Shakespeare Sonnets 1-21).
  Both are at the natural chapter/sonnet-cycle boundary and can be safely truncated
  further if needed.
